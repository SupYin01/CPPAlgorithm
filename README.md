# CppAlgoLab —— 我的 C++ 算法练习实验室

用于：**项目开发、算法练习、刷题、沉淀可复用代码**。
每个算法/数据结构一个编号子项目，结构统一，练完即沉淀。

## 目录约定

```
CppAlgoLab/
├── README.md              ← 本说明
├── PROMPT_TEMPLATE.md     ← ★ 通用提示词：学新算法时复制它，不用重写需求
├── 01_red_black_tree/     ← 红黑树练习项目（进行中）
├── library/               ← 可复用代码沉淀区（成品才放这，须附最小自测）
├── playground/            ← 随手实验、算法草稿，随便扔
└── .gitignore
```

以后新增子项目：`02_avl_tree`、`03_trie`、`04_skip_list`……两位序号 + 下划线 + 算法名。

## 每个子项目的固定结构

```
0X_xxx/
├── README.md      算法思想、口诀/性质、与相近算法的对比、练习顺序、常见坑
├── practice/      练习版：骨架完整、核心逻辑留空（编号 TODO + 注释提示 + 示意图）
├── answer/        参考答案：接口与练习版一致，注释讲"为什么"
├── tests/         无第三方依赖的测试：性质校验 + 边界 + 对抗输入 + 与对比算法量化
└── run_tests.sh / build.bat    一键编译运行（支持对答案跑同一套测试）
```

## 新学一个算法的流程

1. 打开 `PROMPT_TEMPLATE.md`，复制提示词正文，替换【】占位符，发给 AI；
2. AI 会按上面的固定结构生成子项目；
3. 按项目 README 的推荐顺序完成 TODO，随时 `run_tests.sh` 自测；
4. 练完后把通用、稳定的代码（模板、工具函数）整理进 `library/` 并附最小自测。

## 编译环境

- 编译器：g++（MinGW-w64，本机已装 8.1.0）或 clang++，统一 `-std=c++17`；
- 各项目内的一键脚本会自动加好 `-I` 包含路径与 `-O2 -Wall -Wextra`；
- Windows cmd 下中文乱码时先执行 `chcp 65001`。
